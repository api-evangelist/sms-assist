# SMS Assist (Lessen) — One Open API v2

> SMS Assist, now Lessen, runs the "One" Platform for facilities maintenance, repair, and work-order management across residential and commercial properties. The One Open API v2 is a GraphQL API split into a Client surface (create/track reactive and recurrent work orders, residents, locations, invoices, proposals, Turn/Reno projects) and a Vendor surface (assets, communications, messages, work orders for affiliate technicians), with a rich webhook event catalog, SSO/SCIM, and isolated sandbox and production environments. Legacy REST v1 and Affiliate API v1 were sunset in favor of v2 GraphQL.

## APIs
- [One Open API v2 - Client (GraphQL)](https://meshlive.lessen.com/one-graph-client/graphql): Client work-order, invoice, proposal, resident, location, and Turn/Reno operations.
- [One Open API v2 - Vendor (GraphQL/HTTP)](https://meshlive.lessen.com/one-graph-vendor/graphql): Vendor/affiliate asset, communication, and work-order operations.

## Auth
- Token-based bearer auth. POST HTTP Basic Auth credentials to the environment /token endpoint to obtain an access_token, then send it as a bearer token on every GraphQL request. Tokens expire per `expires_in` (Unix epoch). Unauthorized calls return 401.
- Client token: https://meshlive.lessen.com/one-graph-client/token
- Vendor token: https://meshlive.lessen.com/one-graph-vendor/token
